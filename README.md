# Tatenda Jonathan — Client Portfolio Website

This is a lightweight client-facing portfolio site built with HTML, CSS and vanilla JavaScript.

## Files
- `index.html` — content and structure
- `styles.css` — design and responsive layout
- `script.js` — mobile menu, filters and video modal

## Before sharing it with clients

### 1. Add your real project videos
In `index.html`, replace:
- `YOUR_VIDEO_LINK_1`
- `YOUR_VIDEO_LINK_2`
- ...through `YOUR_VIDEO_LINK_6`

Use normal YouTube or Vimeo links. The JavaScript converts them to embeds automatically.

### 2. Add your showreel
In `script.js`, replace:
`YOUR_SHOWREEL_LINK`
with your YouTube or Vimeo showreel URL.

### 3. Add contact details
In `index.html`, replace:
- `YOUR_EMAIL@example.com`
- `YOUR_WHATSAPP_LINK`

Example WhatsApp format:
`https://wa.me/27XXXXXXXXX`

### 4. Rename sample projects
Search `index.html` for these sample titles:
- Brand Campaign Film
- Executive Storytelling
- Vertical Content Series
- Event Highlight Film
- Product Story
- Podcast Visual Package

Replace them with your actual project names and client/project descriptions.

## Publishing options
You can publish this folder on:
